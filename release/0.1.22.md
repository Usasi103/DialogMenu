# DialogMenu 0.1.22

0.1.22 正式发布，累计包含已验证的功能与修复，保留历史版本和预发布附件。

- 支持 `<image:命名空间:图片ID>`、显式 CE/CraftEngine 与 IA/ItemsAdder 前缀，以及 CE 图集行列。
- 翻译由 DialogMenu 的 `text.yml` 和 `translations/*.yml` 管理：i18n 使用默认语言，l10n 使用玩家客户端语言并回退，无须修改 CE 翻译配置。
- 包含 0.1.21 的通用兼容与资源自动导入功能，以及后续放宽合法输入根目录联接的路径检查修复；保留目录内越界保护。
- 附中文 Wiki、图片/物品来源说明和可复制的多语言菜单示例。

## 验证

- 106 项测试通过，0 失败；源码格式检查通过。
- 实际发布 JAR 在独立 Paper 26.2 build 123 + CraftEngine 26.9.1 通过真实图片、多语言、配置检查和重载前后探针。
- 功能代码与用户已测试版本一致，以正式版本号重新构建并验证；此前 Minecraft 26.2 截图已确认中文翻译、玩家名参数和两种 CE 图片写法正常。

## 尚待实测
