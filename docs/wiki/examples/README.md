# 可复制菜单

这些文件由 ../quick-start.md、../examples.md 和 ../migration.md 中标注的完整代码块生成。

选择需要的 .yml 复制到 plugins/DialogMenu/menus/，执行 /dmenu check、/dmenu reload，再 /dmenu open 文件名（不带扩展名）。

请勿覆盖自己的同名菜单；备份放服务器目录之外。

- hello.yml：入门
- preferences.yml：语言与主题
- guide.yml：两页对话
- trial.yml：难度确认
- item-preview.yml：原版物品
- migrated-help.yml：迁移后的完整结构
